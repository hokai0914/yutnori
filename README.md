# 윷놀이 말판 🪧

실제 윷은 **오프라인에서 직접 던지고**, 그 결과에 따라 **말을 놓는(이동시키는) 것만** 도와주는 웹 윷놀이 말판입니다. 프레임워크·빌드 도구 없이 순수 HTML/CSS/바닐라 JavaScript로 만들었습니다.

## 실행 방법

별도 설치 없이 [`index.html`](index.html)을 브라우저로 열면 바로 실행됩니다. (외부 요청·모듈이 없어 `file://` 로도 동작합니다.)

```bash
# 혹은 로컬 서버로 열기
python -m http.server 8000
# → http://localhost:8000
```

## 주요 기능

- **오프라인 결과 입력** — 랜덤 없음. 직접 던진 결과를 `백도 / 도 / 개 / 걸 / 윷 / 모` 버튼으로 입력합니다. 각 버튼에는 배(밝은 면)가 위로 향한 개수를 나타내는 윷 막대 아이콘이 표시됩니다.
- **이동 목적지 미리보기** — 결과를 선택하면 갈 수 있는 위치를 보드에 고스트 마커와 경로선으로 보여주고, 클릭해서 이동합니다.
- **자동 턴 넘김** — 던진 결과를 모두 쓰고 추가로 던질 권리(윷·모·잡기)가 없으면 자동으로 다음 플레이어에게 넘어갑니다.
- **플레이어 이름 설정** — 시작 전 두 플레이어의 이름을 정할 수 있습니다.
- **현재 차례 강조** — 보드 테두리·상단 배너·점수 카드가 현재 플레이어 색(1P 빨강 / 2P 파랑)으로 함께 강조됩니다.
- **완주 현황** — 각 플레이어의 완주 말 개수를 `★ X / 4` 로 표시합니다.

## 반영된 규칙

- **지름길** — 우상단·좌상단 모서리 또는 중앙에 **정확히 멈췄을 때만** 대각선으로 진입, 중앙에서는 도착 방향 지름길
- **백도** — 지나온 경로를 따라 한 칸 뒤로 (대각선 경유도 정확히 되돌림)
- **잡기** — 상대 말이 있는 칸에 도착하면 상대 말을 집으로 보내고 한 번 더
- **업기** — 같은 칸의 내 말은 함께 이동
- **윷·모 한 번 더** — 윷(4)·모(5)가 나오면 한 번 더 던지기
- **완주 / 승리** — 출발점을 지나면 완주, 4개의 말이 모두 완주하면 승리

## 게임 진행

1. 시작 화면에서 두 플레이어 이름을 입력하고 시작합니다.
2. 실제로 윷을 던진 뒤, 나온 결과 버튼을 누릅니다. (윷·모·잡기면 한 번 더)
3. 사용할 결과를 선택하고, 보드에 표시된 목적지를 클릭해 말을 옮깁니다.
4. 결과를 모두 사용하면 자동으로 다음 플레이어 차례로 넘어갑니다.
5. 4개의 말을 먼저 완주시키는 플레이어가 승리합니다.
